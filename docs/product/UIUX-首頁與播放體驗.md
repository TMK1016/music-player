首頁標籤能點選及左右切換；清單橫向捲動與頁面切換不可搶手勢。正在播放維持完整封面與控制，窄螢幕／大字體時允許必要捲動，避免為「一頁」裁掉功能。無歌曲、缺封面、搜尋無結果、空歌手及匯入失敗均須有狀態。科技藍沿用。車輛與開發日誌的既有入口建議移入設定，屬導覽提案，須由介面稿確認。

## 功能規則

### 搜尋與匯入

搜尋範圍至少歌曲名稱與歌手；是否含專輯沿用現有搜尋能力。『近期搜尋結果』可能指關鍵字歷史或最近點選的結果，待確認，不能只做關鍵字便宣稱等同完整需求。建議先展示近期關鍵字及可清除紀錄，另評估最近點選歌曲。匯入仍用系統選檔、複製、解碼驗證、去重與交易式入庫。

### 清單與評分

9種系統類型中，星級分成5張清單，合計為9張系統清單：我的最愛、最近新增、5星、4星、3星、2星、1星、喜好、陌生。收藏是布林值；評分是未評分或1～5星，彼此獨立。3星同時屬喜好與陌生，不能擅自改為互斥。未評分是否歸陌生待確認。最近新增的排序依匯入時間；取最近多久／幾首仍待決策。

系統清單由規則即時計算，不複製音檔；使用者清單引用track ID。可調整顯示順序。系統清單建議隱藏並可還原；刪除自訂清單不刪歌曲。從自訂清單移除歌曲與刪除曲庫歌曲是不同動作。新增、改名、重名、空名稱、刪除及空清單都有可觀察結果。

### 歌手與人工資料整理

每首歌可修改歌名與歌手；以穩定artist ID和可重用標籤連結，不以名字字串充當永久身分。歌手可改名及換頭貼，同一artist ID下的歌曲同步呈現。是否允許一曲多歌手、同名歌手及合併歌手先定義。頭貼需複製到App管理區，拒絕不支援檔案，取消不改舊圖。

歌手列表按歌曲數、名字筆畫、喜好排序；升降序與並列規則需明確。筆畫排序不能冒稱一般字母／Unicode排序：需實測繁體中文筆畫排序能力及混合語言回退規則。『喜好高低』建議使用已評分歌曲平均星等，未評分排後；這是提案，尚未確認。展開B歌手就收合A，收合不影響播放。

未知歌曲先以人工編輯完成，顯示未填欄位，不產生AI猜測作者、封面或歌名。現有所有匯入檔的artist為『本機音檔』，遷移時應區分這個預設值與真實歌手。

### 排行與播放事件

保留當月榜與單一歌曲榜兩個入口；單一歌曲榜是否表示不限月份累計待確認。不能把兩份同範圍資料當成不同功能。需先確認有效播放門檻、短曲、重播、手動跳過、拖曳與跨月計次方式。計畫候選採Asia/Taipei自然月、只計實際播放、同一播放session只達標一次；未確認前不實作統計門檻，不推算假紀錄。

### 正在播放與音效

收藏短按切換，長按開評分；避免長按放開後再觸發短按。另有明確『評分』可及性入口。評分改變更新清單分類，但不強制中斷當前歌曲；下一首依何時產生的篩選快照，須於播放佇列規格固定。

播放模式需拆成『順序／隨機』與『不重複／單曲重複／清單循環』兩個概念，才能精確表示組合；使用者所稱『重播』是否為單曲重複先確認。上一首重新播放或跳到上一首的時間門檻亦先定義。

音效：全域模式忽略歌曲綁定，所有歌使用同一完整SoundProfile；單曲模式優先套用指定模式，沒有綁定時使用全域備援。這是本次兩種使用方式的工程提案，與現有自動套用綁定需做明確遷移。保留自訂ID、7段、低音、空間與20組上限。低音數值微調及EQ細調放設定，播放頁快速切模式。刪除模式後解除綁定並恢復合法備援。

### 重複歌曲搜尋

已有內容雜湊去重可阻止相同檔案再次匯入，但不等於能辨認不同編碼的同一首歌。首期建議搜尋完全相同內容，或依標題／歌手／長度列『疑似』候選；僅人工確認，絕不自動刪除。指紋／AI相似歌曲辨識另作後續能力，不偽裝成目前已具備。

## 資料與實作順序

先擴充有版本的TrackMetadata（覆寫標題、artist IDs、未評分／1～5星、匯入時間）、Artist（頭貼資源）、Playlist及排序、SearchHistory、PlaybackEvent、全域／單曲音效策略。保留歌曲內容ID與舊收藏、曲庫、自訂模式及歌曲綁定。遷移前備份、交易式提交；欄位缺失採可解釋預設，不重置舊資料。

1. 曲庫與歌手資料契約／遷移，再做人工編輯。
2. 評分、系統／自訂清單與加入清單。
3. 三分頁導覽、首頁標籤、歌手展開與播放器。
4. 搜尋紀錄、播放模式及音效策略整合。
5. 有效播放規則確認後才做排行榜。
6. 重複候選檢查、完整回歸與真機驗收。

以上仍需保留既有離線可靠性及EQ真機驗收工作，不用新增功能掩蓋待驗證項目。

## 已有與新增界線

已有：搜尋、系統選檔匯入、內容雜湊去重、收藏、基本隨機／列表循環、EQ及每曲綁定。新增：三頁導覽、近期搜尋、清單CRUD／排序、歌手編輯與頭貼／展開、評分篩選、播放統計、重複檢查介面、單曲重複與明確音效策略。不能以已有部分能力宣稱新版需求完成。

## 驗收計畫（本輪未執行新功能測試）

| ID | 起始條件與步驟 | 預期與邊界 |
|---|---|---|
| UX-T01 | 空曲庫開首頁→搜尋→取消匯入 | 顯示空狀態，不產生假歌曲／紀錄 |
| UX-T02 | 有曲庫搜尋並選結果→重啟 | 正確結果，近期資料依確認規則保留且可清除 |
| UX-T03 | 新增清單→加入歌曲→重排→刪清單 | 順序持久化，歌曲與其他清單仍在；同曲不重複引用 |
| UX-T04 | 歌曲從未評分→3星→5星，另切收藏 | 3星入兩類，5星只入喜好；收藏不改星等 |
| UX-T05 | 歌手A展開→B展開→改B名及圖→重啟 | 僅B展開，作品引用不斷裂，取消換圖不改舊圖 |
| UX-T06 | 舊曲庫升版→編輯歌名／歌手 | 舊收藏、內容ID及模式綁定保留；壞資料不覆寫 |
| UX-T07 | 播放頁短按收藏→長按評分 | 不互相誤觸；封面缺失、長歌名、大字仍可操作 |
| UX-T08 | 0／1／多首清單分別切隨機、重複、循環 | 不越界、無候選不亂播、進度恢復按已定規則 |
| UX-T09 | 全域切曲→開單曲策略→無綁定曲→刪被綁模式 | 全域一致，單曲優先，缺值合法備援，不影響歌曲資料 |
| UX-T10 | 暫停／拖曳／跨月／重播／重啟 | 依已確認計次規則不漏計、不重計，月份與累計範圍明確 |
| UX-T11 | 相同檔案與不同編碼同名歌曲→檢查重複 | 完全相同與疑似清楚區分，未確認不刪檔 |
| UX-T12 | 缺歌名歌手→人工填寫→重啟 | 保存人工資料，不聲稱AI識別或自動查證 |

## 仍待確認

排行榜第二種範圍；未評分歸類；系統清單隱藏／刪除；近期搜尋的內容；最近新增時間範圍；有效播放門檻；歌手喜好算法與多歌手；『重播』含義。先確認會影響資料結構的項目，再以可點介面稿確認位置。
