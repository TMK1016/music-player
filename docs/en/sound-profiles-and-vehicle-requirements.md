# Sound profiles and vehicle tuning requirements

Date: 2026-10-24. Faithful English translation of the new user requirements; engineering limits are documented separately.

I have looked at other music apps. They offer an additional bass enhancement feature and more listening modes than our current Original, Bass, Vocal, and Night modes. Please implement bass enhancement and additional modes. Also add custom modes, with a maximum of 20 custom modes. Each custom mode must be nameable. I want to be able to assign a particular mode to a particular song so that the mode is applied when that song plays. Please implement these features.

What do numbers such as 32, 64, and 128 mean in the equalizer? How do they help with sound adjustment? Can we develop different styles such as surround sound and concert sound?

The vehicle settings are not complete yet. Please continue improving them. Users should be able to select their speaker types. For example, my car has one component-speaker set on each side in the front and one coaxial-speaker assembly on each side in the rear. Component speakers separate the tweeter from the mid/woofer: the tweeter is usually higher up and the mid/woofer lower down.

Can we reproduce a listening demonstration similar to a Dolby demo, where each speaker produces sound separately? Can the equalizer and mode selection improve the component speakers so that the tweeter reproduces the high-frequency characteristics while the mid/woofer fulfills its own role?

The driver's seat is usually the primary listening position. Are there reference data that we can use for adjustment so that the driver hears the best possible sound? I would like to replicate DSP functionality, allowing drivers to get as much benefit as possible from their existing speakers without buying an expensive amplifier.

Additional confirmed hardware information: the car is a 2017 Ford Fiesta B299-7v. The phone connects to the car through Bluetooth. There is no external DSP. The head-unit model, existing internal processing, exact crossover wiring, driver models, and measured seat-to-driver distances have not been provided.

Continuing requirements: retain the approved technology-blue interface; update the interactive flow inspector and the development journal for every change, with links to the corresponding features, nodes, and source locations. Use Traditional Chinese for the response and retain this English translation for review.
