# Inline modes and save prompt requirements

The current mode selection achieves the initial desired effect. After swiping horizontally, however, all modes should expand beneath the original horizontal strip rather than opening a new window. For adding a mode, show “Save new mode” after the user manually moves an equalizer slider.

Implementation interpretation: show a nonblocking save button after manual slider adjustment; open the naming form only when the user presses it. Keep existing custom-mode management and the twenty-mode limit.
