# 官方來源與查證記錄

查證日期：2026-10-24。來源可能更新；實作與送審前應再次核對。以下為摘要，不代表法律意見或授權已取得。

| 來源 | 支持的結論 | 限制 |
| --- | --- | --- |
| [YouTube Developer Policies](https://developers.google.com/youtube/terms/developer-policies) | 一般 API 政策限制未經允許的下載、離線副本與影音分離 | 不推論未公開的商業合作不存在 |
| [YouTube Music 官方說明](https://support.google.com/youtubemusic/answer/6312991?hl=en) | Premium 可在官方產品內離線收聽 | 沒有提供本 App 讀取離線檔案或 DSP 的依據 |
| [App Review Guidelines 5.2.2／5.2.3](https://developer.apple.com/app-store/review/guidelines/#intellectual-property) | 第三方服務存取及影音下載需要符合條款／來源明確授權 | 不能保證送審通過 |
| [CarPlay entitlement](https://developer.apple.com/documentation/carplay/requesting-carplay-entitlements) | 整合 CarPlay 需申請相應資格及設定 | 不代表取得多通道硬體控制 |
| [CarPlay 音樂 App 整合](https://developer.apple.com/documentation/carplay/integrating-carplay-with-your-music-app) | 原生 CarPlay 音樂整合路徑 | 實際支援版本與範本於實作時確認 |
| [Audio Engine](https://developer.apple.com/documentation/avfaudio/audio-engine) | Apple 有音訊節點圖與即時播放框架 | Rust 混合架構是工程建議，仍需 spike |
| [AVAudioSourceNode render block](https://developer.apple.com/documentation/avfaudio/avaudiosourcenode/init(format:renderblock:)) | 硬體回呼應避免阻塞 | 跨語言橋接的即時安全必須自行驗證 |
| [Apple 工程師即時音訊說明](https://developer.apple.com/forums/thread/772060) | 回呼應避免配置、檔案 I/O、鎖及 runtime 互動 | 論壇中的使用者陳述不視為 Apple 官方承諾 |
| [有效輸出通道](https://developer.apple.com/documentation/avfaudio/avaudiosession/outputnumberofchannels) | 檢查當前路由通道數與最大能力 | 通道數之外還須驗證實體映射 |
| [多路由 session](https://developer.apple.com/documentation/avfaudio/avaudiosession/category-swift.struct/multiroute) | 多路由取決於路由能力且需處理變更 | multiRoute 不等於能控制所有車內喇叭 |
| [Playback session](https://developer.apple.com/documentation/avfaudio/avaudiosession/category-swift.struct/playback) | 鎖屏／背景播放需適當 session 與背景能力 | 真機中斷與耗電仍須測試 |
| [Directory access](https://developer.apple.com/documentation/uikit/providing-access-to-directories) | 選檔器可存取本機／iCloud／File Provider；需 scope 與協調 | 雲端 URL 不是完整離線音檔 |
| [Developer ID](https://developer.apple.com/help/account/certificates/create-developer-id-certificates/) | Mac 商店外發佈可簽章與公證 | 不適用直接替代 iOS 公開分發 |
| [Beta 與發佈](https://developer.apple.com/documentation/xcode/distributing-your-app-for-beta-testing-and-releases) | Apple 區分測試、商店與 Mac 直接分發 | 方案資格與地區仍需逐次確認 |
| [Rust editions](https://doc.rust-lang.org/book/appendix-05-editions.html) | Rust 2024 是官方支援 edition | 不是最新編譯器版本號；尚未安裝工具鏈 |
| [Symphonia 官方 README](https://github.com/pdeljanov/Symphonia/blob/main/symphonia/README.md) | codec／容器與 feature flags 分開，提供 Rust 解碼 | gapless 與支援程度需按格式驗證；MPL-2.0 需評估 |
| [miniDSP 主動分音](https://support.minidsp.com/support/solutions/articles/47000681676-what-is-an-active-crossover-) | 主動分音在擴大前分離頻段；被動分音在後端以元件處理 | 未知使用者實際接線，不據此判定其系統 |
| [miniDSP 時間對齊](https://www.minidsp.com/applications/rew/182-time-alignment-basics) | 可藉個別延遲與量測進行時間對齊 | 不存在通用車型延遲值 |
| [miniDSP 車用調音](https://www.minidsp.com/applications/car-audio/3-car-audio-tuning-dsp) | 路由、延遲、分頻及量測是車用調音要素 | 不保證任何預設能達到最佳音質 |
| [Homebrew 官方安裝](https://brew.sh/) | 官方 shell 安裝指令及 Apple Silicon 標準 prefix | 本環境無法解析下載主機且沒有 prefix 寫入權限，尚未安裝 |

查證過程：firecrawl CLI 已存在，但連 `api.firecrawl.dev` 時 DNS 解析失敗，改用可用的網頁工具搜尋官方頁面。部分 Apple 頁面為 JavaScript 殼，改用官方索引摘要與相應文件交叉確認；沒有宣稱已閱讀不可取得的完整內容。沒有安裝 firecrawl 或其他新技能。
