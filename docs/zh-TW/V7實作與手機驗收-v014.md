2026-10-28｜v0.14.0／build18。使用者已明確授權「完整修改並更新至手機端」。原始需求與8圖對照、常見做法與歷史基準保留於[V7評估](V7效能與音訊架構評估.md)，本文件區分實作、測試與真機證據。

## 已接入App

| 項目 | 最終行為與位置 |
| --- | --- |
| 資料計算 | LibraryIndex.swift建立track／artist／清單／月與累計統計／排序快照。artist／playCount／清單讀取改查索引，沒有在比較器反覆掃全庫；同一資料版本重用快照 |
| 冷載入與匯入 | PlayerModel先在背景建立完整快照，再原子公布曲目及對應索引；版本／請求代次防止過期載入覆蓋新資料。編輯仍有一次線性同步回退，保證資料當下正確，不冒稱所有計算都零成本 |
| 首頁與排序 | 單一ScrollView＋LazyVStack；分類、展開、批次與捲動錨點由HomeLibraryState持有。全部歌曲的排序Button提供自訂／歌名／歌手／最近新增；拖曳或上下移切換成全庫自訂順序 |
| 50首增量 | 全部歌曲初始50首，底部「載入更多50首」接續；本輪採明確按鈕控制。搜尋、排行榜及播放／隨機佇列仍涵蓋全曲庫，不被顯示批次截斷 |
| 儲存壓力 | CollectionWriter最多保留正在寫的一份及最新待寫快照，合併連續修改；flush等待保存。完整最新狀態內包含所有播放事件，不靠丟棄事件換效能 |
| 圖片 | 解碼快取按128／256／512／768等尺寸區分；離開可見範圍釋放View自己的bitmap，快取有成本／數量上限。保留原有方向修正、裁剪及來源保護 |
| 音訊控制 | 音量變動不再重設EQ濾波器；格式不變時只改變有差異的gain／bypass。低音／殘響與前級值相同就不重寫。保留AVAudioEngine、七段、既有前級策略及首次I/O偏好，不新增另一響度／限幅策略 |
| 可追蹤性 | Points of Interest及performance／storage／audio-continuity分類記錄頁面、分類、曲庫就緒、保存大小等；不記錄曲名、音訊內容或完整私人路徑。實時render沒有加入JSON／圖像或磁碟操作 |
| 工具與迷你播放器 | 右側箭頭保留；六工具盤霧面漸層與淡邊框。迷你播放器使用封面小尺寸模糊背景或既有藍色漸層、2pt進度、與頁籤列分隔；進度仍由獨立PlaybackClock更新 |
| 表單與評分 | 中央封面＋相機選單，選照片／檔案／移除個別封面回歌手備援，沿用裁剪。歌名／歌手欄與取消／儲存重排。五星右方垃圾桶只在已評分時顯示，清除後隱藏；刪App音檔仍另有二次確認 |
| 鎖屏封面 | iOS加入MPMediaItemArtwork，沿用個別封面→歌手頭貼→系統音符備援。圖片解碼非主執行緒、以曲目／圖片資料代次忽略過期結果；換無圖歌曲清掉舊圖。每秒進度沿用同一Artwork物件 |
| 密度與尺寸 | EQ模式標籤視覺76×32pt、間距4pt，透明觸控範圍仍44pt；長按排序／點選套用／選定置中保留。短橫向播放頁改左右分欄，EQ仍沿用單頁無上下捲動 |
| 日誌入口 | 手機首頁補側邊欄Menu進開發日誌，未恢復已移除的設定更多群組。流程圖及App共用同一版本日誌來源 |

資料相容：不更名舊bundle／曲庫／偏好ID；新增可選songSort欄，保留歌曲、收藏、評分、清單、圖片、音效模式與綁定。沒有改資料庫格式或移動私有音檔。匯入進行中暫拒絕刪檔以避免資料版本競爭。

## 自動驗證與量測

- `scripts/check_audio.py`：既有12組與新增V7檢查；覆蓋1230／5000／10000首、完整統計、評分／收藏／歌手改名失效、排序後轉自訂、50首顯示不截播放佇列、切頁不load／stop／configure音訊、背景預建及1000事件合併保存。測試使用合成資料及FakeAudio，不使用私人曲庫。
- `scripts/benchmark_library_index.py`測正式LibraryIndex、arm64 Swift6 -O、單次合成取樣：1230首／200歌手／4920事件建立14.96ms，5000首36.37ms，10000首73.90ms；各組100次暖讀取合計約0.08ms。原始JSON見docs/technical/v7-production-index-release.json。這不是手機切頁／音訊延遲。
- Debug索引時間另保存於docs/technical/v7-production-index-debug.json；冷建立比Release慢。載入／匯入先在背景預建；不以Debug冷建立數值冒稱暖切頁表現。
- 歷史慢算法基準腳本固定從330020e讀取8份來源及原探針，避免正式Model優化後悄悄改變舊基準。原量測JSON不覆寫。
- 512MiB連續兩次雜湊仍保留記憶體界線回歸，沒有撤回V6每塊autoreleasepool。
- 2026-10-28 02:11:43原生離線PCM報告更新：800Hz +6.00dB、旁通補償−6.00dB、32Hz低音5.90dB、殘響尾音0.00046491／旁通0、130響應探針最大模型誤差0.033dB。見docs/technical/v7-native-pcm-result.txt。只在記憶體渲染，不出喇叭；不是實車無雜音驗收。
