# 首頁連續捲動與防誤觸

0.19.0／build26，2026-10-29。依使用者標註圖實作；對應 LIB-01、UI-01、QA-01。

## 修正

- 播放清單不再先截成三個、再因向下手勢突然展開。全部可見清單使用 LazyVGrid 連續呈現，新增播放清單在最後。封面寬高比調為 1.4，縮短卡片，讓第三排在一般尺寸可露出部分；實際露出數量仍取決於螢幕與字級，不以隱藏清單達成。
- 三個分類共用固定 44pt 資訊列、20pt 左右邊距，左側為清單／歌手／歌曲數，右側為排序；分類標籤仍固定 56pt。歌手上方不再另外保留一份資訊列。
- 清單排序支援自訂順序、名稱筆畫、歌曲數目。非自訂模式再次選取可反向；拖曳重排回到自訂順序。新增欄位為 optional，舊 collection-v1.json 可讀，不重建曲庫。
- 捲動位置改成不發送 ObservableObject 更新的內部狀態，避免每次位置回寫讓首頁重新評估。
- 原生捲動中、減速中及結束後 250ms 暫緩歌曲／封面／管理按鈕啟動；真正拖曳同樣設置短暫防誤觸。靜止按下的 tracking 階段不封鎖，一般點按仍有效。橫向門檻保留，垂直手勢只捲動。iOS18／macOS15 以上使用 ScrollPhase；較舊版本使用拖曳保護。

## 驗證

- `scripts/check_audio.py`：16 組模型檢查通過；新增滑動防誤觸時序、清單排序反向與序列化，以及 1000 次位置回寫不發送 objectWillChange 的回歸檢查。
- `scripts/check_v8_ui.py`：原生 SwiftUI 驗證程式編譯通過。使用隔離的 1231 首合成曲庫，正常點按可播放；七個清單皆存在，新增按鈕最後；畫面第三排可見；可捲到底再回頂端，分類資訊列共享相同版面。排序選單三個選項可開啟。
- 尚未量測真機 FPS；原生桌面驗證不代表真機觸控／藍牙聽測通過。本輪未修改 DSP，不宣稱消除所有音訊雜音。
