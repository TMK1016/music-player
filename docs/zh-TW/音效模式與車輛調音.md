## 已實作

- 13 組預設：原音、低頻、人聲、夜間、流行、搖滾、爵士、古典、電子、木吉他、語音、溫暖、演唱會。這是偏好起點，不是特定車輛量測出的校正。夜間是削弱低頻與高頻的音色預設，沒有動態壓縮。
- 90 Hz 低架濾波低音增強，0～+9 dB，步進 0.5 dB；與 10 段 EQ 分開調整。保留前級衰減，並對啟用殘響增加 6 dB 餘裕。不是自動限幅器，不保證外部車機／喇叭不失真。
- 原生立體聲殘響：關閉、錄音室、演唱會、音樂廳、寬廣空間；混合 0～35%。使用 AVAudioUnitReverb 的小房間／大廳／中廳／大室預設。沒有 Dolby 授權、Atmos 解碼、頭部追蹤或獨立多聲道環繞。
- 最多 20 組自訂音效；可新增、命名、重新命名、用目前調音覆蓋及刪除。名稱修剪首尾空白，1～30 字，拒絕重名。保存 10 段 EQ、旁通、低音與空間設定；不保存音量或車輛幾何。
- 每首歌可綁定內建或自訂模式。選曲、下一首及自然結束換曲共用選曲路徑；無綁定時恢復綁定前的一般調音。手動選模式會更新一般調音；下一次進入已綁定歌曲仍套用綁定。刪除模式會清除引用它的歌曲綁定。
- 設定 v2 持久化並讀取舊版 v1。綁定使用既有歌曲內容識別碼；重新匯入相同內容不會因檔名改變而變成另一首。
- 車輛名稱與連線、前後二／三音路分音／同軸／全音域／未安裝、超低音標記、四個座位；各座位的距離分開保存。未量測保持空白。
- 原創左右與中央音像試音（2 秒、500／1000／2000 Hz 混合、低數位電平及淡入淡出）。測試暫停音樂、旁通音效、使用獨立低播放音量；結束不自動恢復音樂。中央是 L=R，不是實體中央喇叭。離開車輛頁、按停止或重新選曲即取消試音。

操作：等化器頁調整音效 →「儲存目前調音」→ 命名；模式旁的更多選單提供覆蓋／改名／刪除。選擇歌曲後，在同頁「歌曲自動套用」選模式。車輛頁設定配置、選量測座位，再填距離。

## 32／64／125 的意義

Hz 是每秒振動次數；這些是濾波頻段中心頻率，不是音質等級或喇叭編號。本 App 是 125 Hz，並非 128 Hz。頻帶彼此重疊，這裡的音色描述是一般方向，不是各樂器只佔一段。

| 頻段 | 常見聽感方向 | 調整取捨 |
|---|---|---|
| 32 Hz | 極低頻延伸、震動感 | 喇叭若無此能力，提升可能只增加負擔 |
| 64 Hz | 低頻重量、鼓與貝斯基音的一部分 | 過多容易轟鳴 |
| 125 Hz | 低音厚度與衝擊 | 過多可能膨脹 |
| 250／500 Hz | 溫暖、聲音厚度 | 過多可能混濁，削太多則單薄 |
| 1k／2k Hz | 人聲、中頻存在感 | 提升可能更靠前，也可能鼻音或生硬 |
| 4k Hz | 清晰、輪廓 | 提升過多可能刺耳 |
| 8k／16k Hz | 亮度、細節、空氣感 | 不能恢復音源不存在的細節，也受喇叭與聽覺條件限制 |

dB 是增益，0 是該濾波器不增減，負數削減，正數提升。先以原音、關閉殘響開始，每次調整 1～2 dB；在相近聽感音量下比較。預設與低音增強會配合前級衰減，因此某些模式整體比較小聲，不能把「大聲」直接當成「更好」。這也不等於已完成感知響度正規化。

## 使用者已確認與未知項目

已確認：2017 Ford Fiesta B299-7v；藍牙；沒有外接 DSP；前左右分音、後左右同軸（來自使用者描述）。這些是設定預填，並非 App 偵測結果。未確認：車機型號、是否原廠、內部 EQ／分頻／音場功能、實際接線及分音方式、單體規格、外接擴大機狀態、聆聽距離。沒有外接 DSP 不代表車機內部完全沒有 DSP。

目前 App 只產生 L/R 立體聲。車機如何把 L/R 分送前後，是車機內部的處理；App 沒有逐單體映射。前後喇叭配置數不能轉換成輸出通道數。若分音發生在車機／被動分音器，App 的整體 EQ 無法繞過它而獨立選中高音單體。選 USB／CarPlay 也不自動解鎖獨立路由；本版所有配置維持立體聲。

因此本次**沒有**加入會誤導的逐喇叭播放按鈕、任意分頻點、實際逐路延遲或一鍵皇帝位。逐單體主動分音必須先有獨立輸出與放大通道，以及單體規格與保護條件。軟體 DSP 可處理可存取的訊號，但不能提供功率、改變接線、增加喇叭行程，或保證現有硬體發揮某個百分比。

## 定位參考與下一步

每個座位都需自己的距離。約 20°C 聲速 343 m/s，延遲起點是：

`延遲 ms = (最遠單體距離 cm − 本單體距離 cm) / 34.3`

例如最遠 150 cm、另一顆 80 cm，較近者的幾何補償約 2.04 ms。這不是 Fiesta 專用標準數據，只是算例。單體聲學中心、分音相位、反射與左右音量差都會影響結果；應用校正仍要量測脈衝響應與頻率響應。本版只有全部有效距離填妥才顯示結果，且只保存參考，不對藍牙輸出套用。

目前較實際的車內驗證順序：停車、固定音量／座位，先以原音與關閉空間效果建立基準，檢查車機自己的 EQ 是否同時增強；再小幅削減明顯轟鳴或刺耳的頻段，保存個人模式。要進一步驗證駕駛位，可用校正量測麥克風及 REW 記錄頻響，不能靠喇叭數量推導通用最佳值。未量測前不提供假裝精準的 Fiesta 校正表。

## 查證來源

- [Apple AVAudioUnitReverb](https://developer.apple.com/documentation/avfaudio/avaudiounitreverb)：原生殘響單元。實際 API 另以本機 SDK 編譯及 PCM 驗證。
- [Apple outputNumberOfChannels](https://developer.apple.com/documentation/avfaudio/avaudiosession/outputnumberofchannels)：音訊路由聲道數，不能從這個數字推導車內喇叭對應。本版沒有宣稱自動偵測每顆喇叭。
- [miniDSP 主動分音說明](https://support.minidsp.com/support/solutions/articles/47000681676-what-is-an-active-crossover-)：主動分音在功率放大前分頻，與被動分音架構不同。
- [miniDSP 時間對齊](https://www.minidsp.com/applications/rew/182-time-alignment-basics)：343 m/s、cm／34.3、相對最遠單體與量測驗證。
