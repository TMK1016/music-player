# 科技藍介面實作與驗收

2026-10-24｜UI-01｜界面原型 v0.1。

## 已確認與尚待確認

使用者確認以 Mac M2、Xcode 開發與打包，希望駕駛透過 App 播放並調整等化器，優先實作科技藍介面。實際播放端、CarPlay、車機型號與獨立音訊通道仍未確認。本輪原生 macOS 可直接執行；iOS 共用相同畫面及狀態，為後續手機驗證保留入口。

## 視覺與操作

- 色彩：深藍 `#080F1B`、面板藍 `#101D2E`、電光藍 `#398CFF`、青藍 `#6BD8FF`，搭配清楚的文字對比。
- 桌面：左側導覽、中央播放卡、右側 EQ 摘要及車輛設定、底部迷你播放器。
- 窄版：單欄內容、底部四頁導覽、播放控制依可用寬度縮減至必要按鈕。
- 封面：以 SwiftUI Canvas 繪製原創軌道／波紋圖，不依賴網路圖片或第三方專輯封面。
- 有真實狀態互動的功能：導覽、搜尋、收藏、切歌、播放外觀、進度拖曳、EQ 預設／自訂／旁通／歸零、座位選取、專注模式及佇列。
- 未接入的音訊、匯入、雲端與車機能力有明確預覽／待接入標示；不顯示假連線、假量測或假下載成功。

## 實作位置

| 檔案 | 職責 | 對應既有節點 |
| --- | --- | --- |
| `apps/apple/OrcaPlayer/ContentView.swift` | 導覽、播放、迷你播放器、專注模式 | PLAY-01 的介面部分 |
| `apps/apple/OrcaPlayer/EqualizerView.swift` | EQ 畫面、示意曲線、頻段滑桿 | EQ-01 的介面部分 |
| `apps/apple/OrcaPlayer/LibraryView.swift` | 搜尋、收藏、來源入口與佇列 | LIB-01／SOURCE-01 的介面部分 |
| `apps/apple/OrcaPlayer/VehicleView.swift` | 車輛與座位配置預覽 | PROFILE-01 的介面部分 |
| `apps/apple/OrcaPlayer/PlayerModel.swift` | 可觀察狀態、示範資料、設定保存與驗證 | UI-01，未連音訊核心 |
| `apps/apple/OrcaPlayer/Theme.swift` | 色票、元件與原創封面 | UI-01 |
| `apps/apple/OrcaPlayer/OrcaPlayerApp.swift` | 原生 App 入口 | UI-01 |

既有音訊與實車節點保持原狀。依此次明確要求，新增可獨立審閱的 UI-01，不把介面完成當成 PLAY-01／EQ-01 功能驗收完成。

## 驗證證據

- macOS arm64 Debug：`xcodebuild` 編譯通過；已在本機啟動原生 App。
- iOS Simulator arm64 Debug：generic Simulator 目標編譯通過。
- 狀態檢查：切歌循環邊界、隨機不重選目前曲目、專輯搜尋、無結果、收藏篩選、設定序列化與還原、異常設定範圍限制、損毀資料恢復、EQ 歸零均通過。
- 原生 UI：已檢視科技藍主畫面截圖；點選等化器後能看到 10 個可存取滑桿；32 Hz 設定改為 5 dB 後數值及預設名稱更新為「自訂」。
- 原生 UI：選低頻預設後切旁通，預設按鈕與 10 個滑桿皆停用，狀態顯示「旁通」。
- 原生 UI：音樂庫輸入 `Ocean`，結果由 5 首變為 1 首；清除後可回復。
- 原生 UI：車輛頁顯示前座分音／後座同軸、座位選取與未連線狀態，未聲稱已偵測車輛。
- 最終版在窄版播放控制加入必要按鈕的自動退讓後，macOS／iOS Simulator 兩個 target 再次編譯通過；Mac 原生 App 重新啟動成功。已產生本機開發預覽 ZIP，未進行公證或對外發佈。

本機編譯過程中發現 Observation 巨集的子程序受執行環境限制而無法啟動，因此改採 Apple 原生 Combine 的 `ObservableObject`／`@Published`；沒有降低系統安全設定。此變動只影響介面狀態管理，不改變 Rust 核心方向。

限制：CoreSimulator 服務不可用，因此未完成 iPhone 模擬器執行、真機、Dynamic Type 全尺寸、VoiceOver 全流程或實車驗證。編譯紀錄的 CoreSimulator 連線錯誤不影響 generic build 成功，但不能據此宣稱手機已測試。尚無音訊正確性、DSP 效能或音質改善證據。
