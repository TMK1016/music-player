# 首頁對齊與清單播放修正

0.19.1／build27，2026-10-29；依兩張21:06標註圖。對應 LIB-01、UI-01、PLAY-01、QA-01。

## 實作

- 三分類排序按鈕僅顯示圖示，保留44pt點按範圍、VoiceOver狀態與原有選單。
- 以可視寬度限制垂直ScrollView及內容，左右各20pt。頂端標記填滿寬度，位置綁定／恢復使用topLeading；task等待版面一輪再定位，減少對未穩定內容寬度的依賴。尚無真機幾何追蹤可證明原始左移現象的唯一原因。
- 封面及新增卡片恢復1:1，名稱／歌曲數置中。正方形素材不再因長方形容器裁去上下；非正方形素材仍沿用封面裁切。全部清單連續懶載入，新增在最後。
- 播放控制依來源清單ID與目前歌曲判定，同清單播放中顯示暫停；暫停後從同一首恢復。歌曲同時在另一清單中，不會把另一清單視為目前來源。
