# v0.9 三頁細節與單頁調音

2026-10-26。完整英文需求對照：docs/en/player-experience-v09-requirements.md。已查看使用者IMG_9770首頁標頭圖片。沿用科技藍、原生SwiftUI及現有音訊後端。

## 變更與決策

- 首頁標頭為「你的音樂庫」，搜尋／匯入圖示置右；搜尋可展開輸入及近期記錄。保留三種曲庫與排行榜。
- 播放頁評分移左上，模式名稱及進入調音按鈕置右上；封面改**向左滑**進EQ。原聲為新安裝預設名稱，builtin.flat與資料識別碼不變、不重置既有設定。
- 播放進度與控制共用固定底部；封面與EQ切換不重新選曲或載入音訊。新增清單管理頁可勾選加入／移除、建立並加入目前歌曲，長按清單可確認刪除整份清單，保留檔案。
- 調音面與設定EQ入口均無上下ScrollView，主要呈現低音與七段EQ；短高度改左右配置，其他高度壓縮曲線／模式標頭、分配滑桿高度。七段仍50/125/315/800/2k/5k/12.5k Hz，不變動濾波規格。
- 低音分十檔0～9 dB，1 dB一步；舊有小數設定保留並顯示實際數值，使用者再次拖動才量化。手動改低音或EQ都會顯示加號儲存模式，回到完整SoundProfile基線則取消提示。
- 模式以左右滑動選擇，取消全部展開功能；iOS 18／macOS 15以上滑動停止後套用對齊模式，亦可直接點選；舊系統保留滑動瀏覽再點選。長按可前移／後移、重新命名、自訂覆蓋／刪除或移除內建。排序隨偏好儲存，舊偏好沒有排序欄位也能讀取。最多20組自訂模式。
- 命名採居中浮框，面板底色50%不透明，另有背景遮罩以維持可讀性；保留空白／長度／重複命名驗證，鍵盤焦點與取消／儲存入口。
- 睡眠預設分鐘5/10/20、歌曲3/5/10；自訂1～120分鐘或1～100首；模型也限界並互斥。延續暫停仍計時、自然播完才扣歌、重播扣歌及跳歌不扣規則。
- 分享只交給系統選擇對象；反饋是可編輯／匯出的文字，沒有未提供的收件信箱或伺服器。隱私政策說明目前本機資料、系統分享及備份行為，並非已完成商店法務審查。

## 驗收故事與情境（PM技能）

1. 聽歌時直接調音：播放歌曲→左滑封面或按模式→七段及低音同時呈現→改值後音訊不重載／暫停。測試正常直向、短高度、模式列滑動不切頁；小螢幕、橫向、大字與VoiceOver需實際UI證據。
2. 儲存與排序：改EQ／低音→出現儲存入口→空白／重名保留錯誤→有效名稱新增→長按前移→重啟排序維持。達20組不可新增，刪除模式清理歌曲引用；已有音效設定保留。
3. 清單與睡眠：目前歌加入兩清單→取消其中之一音檔仍在→新建清單並立即加入→整份刪除需確認。設定120分鐘、100首及超界輸入，換模式清掉另一種倒數，取消恢復未設定。
4. 設定入口：分享不自動傳送；反饋空白不匯出；隱私文字可讀且可關閉。
