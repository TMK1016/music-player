# v0.8 播放頁原位調音

2026-10-26。使用者兩張本機參考圖已實際開啟查閱並保存於docs/design/references，並非憑檔名猜測。設計來源集中於DESIGN.md，使用本機UI UX Pro Max的觸控、可及性及SwiftUI指引。

## 改動

- 播放頁不再顯示技術狀態列或原頂部EQ模式標籤。
- 右上五星始終可見；未評分全空心，支援點選、橫拖及VoiceOver增減／清除。保留未評分不進喜好與陌生、3星進兩類。
- 封面向右滑顯示同頁七段EQ，且可按『調音』或『封面』切換。EQ滑桿不綁切頁手勢，避免左右模式列及垂直滑桿誤觸。
- 進度／時間／播放控制固定在下方，EQ內容再長也不把播放控制一起捲走。
- 加入清單、收藏、定時同一排，圖示各有可及性名稱；未改已有功能規則。
- 四種播放方式整合選單並互斥；原全域／單曲音效策略改放設定，EQ選預設仍遵循該策略。
- 仍沿用7段及既有音訊後端；切面只改UI狀態，不呼叫choose／load／pause。聲音實際處理由現有configure更新。

## 驗收

模型新增評分幾何左右邊界、五區映射、無效寬度／NaN、播放模式互斥，以及播放中改EQ／評分不暫停或重載。版面需另驗證：375pt、橫向、大字、Reduce Motion、VoiceOver、封面右滑及EQ／進度手勢互不衝突。這些不以語法檢查代替。

本輪包含前次尚未提交的v0.7.1音訊通知崩潰修復；其模型回歸與真機狀態分開記錄。v0.8尚未經本輪真機安裝確認。若工具鏈／模擬器缺少元件或環境無法啟動，保留具體錯誤而非宣稱已視覺驗收。

- `scripts/check_audio.py`全數通過，包含背景音訊通知切回MainActor、評分邊界、模式互斥、播放中EQ／評分不重載的模型回歸。
- `planning/validate_plan.py`通過：25節點、21筆日誌／50項改動、14項PM映射；HTML與App日誌資料一致。
- 實際啟動本輪macOS產物，側欄顯示0.8.0。原生畫面確認五顆空心星、封面／歌名／歌手／同排功能；按調音後七段同時呈現，播放進度及控制仍固定在底部；封面與EQ按鈕切換成功。
- 尚未驗收：iPhone實機安裝與觸控、375pt／橫向／大字／VoiceOver朗讀與Reduce Motion實際行為。CoreSimulator服務回報無法取得runtime；本機未提供可啟動的Simulator.app。本輪不宣稱完成手機更新。
