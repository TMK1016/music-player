# V10 詳情輪播與首頁統一

版本：0.17.0／build24。依使用者七張 202610291401xx／20261029140200 標註圖實作；私人截圖與範例人物照片不納入交付資源。

## 已修改的行為

- 清單「＋」為完整圓角方形、歌手「＋」為完整圓形，只顯示加號，保留輔助使用標籤。清單預設符號內縮10%邊距，視覺尺寸約縮小20%，自訂封面不縮。
- 三分類列固定於主捲動區上方，統一56pt高；內容與排序控制不再推動分類列。
- 詳情頁隱藏「你的音樂庫」標頭、名稱置中；橫向封面輪播以同一選定ID同步曲目、背景、編輯／新增與播放全部。相鄰封面暗化、選定封面還原亮度；長清單仍lazy載入。
- 播放全部改成綠色圓形播放圖示，保留既有佇列／循環／隨機政策。新增「＋」搜尋選歌及「…」編輯照片／名稱。
- 自建清單及最愛可批次加入曲庫歌曲，忽略不存在的ID、避免重複。歌手選歌先提示「將改變歌手、從原分類移出」，確認後批次歸類。評分／日期等自動清單的新增按鈕停用並解釋規則，不偷偷修改評分或新增日期。
- 點「首頁」清除詳情選定與搜尋畫面，回到目前分類的根頁；不刪除清單、曲庫或音效。
- 新清單建立頁含自有程序式預設封面、相機選單及既有照片裁切、白色名稱輸入欄、取消／儲存。資料驗證通過才一次保存清單和封面；取消不建立資料。
- App移除開發日誌入口（含寬版側欄），日誌JSON不再放進正式App資源。專案 planning/changelog.json、原生來源副本及互動圖繼續同步維護；legacy developmentLog識別保留作相容用途，不顯示開發內容。
- 首頁右上「＋」與設定頁開啟同一個 LocalMusicSearchView：系統選資料夾、去重、雷達搜尋與勾選匯入，沒有擴大檔案存取範圍。
