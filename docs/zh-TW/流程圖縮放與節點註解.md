# 流程圖縮放與節點註解

2026-10-25，流程工具更新；不更動播放器音訊。

開啟 planning/flow-inspector.html，在依賴圖上方使用縮小、放大、100% 或符合寬度。圖框右下角可拖曳調整高度，寬度隨頁面變化。縮放範圍 30%～175%。

點節點後，在右側「節點註解／修改需求」按「新增註解」。文字自動儲存，可編輯、標記已解決或重新開啟；節點顯示待處理與總數。保留所有內容，不提供永久刪除。

資料保存在同一瀏覽器的 localStorage，清除瀏覽器資料、換瀏覽器或移動 HTML 路徑可能無法取回。請使用「匯出註解 JSON」備份，並交給 Orca 處理；另可匯入同專案 JSON 合併，相同 ID 但內容不同時保留為另一則。匯入驗證節點、格式及 5 MB 檔案限制。儲存失敗會明確提示匯出。

這是節點層級註解，並非 Word 逐字選取批註。註解不會自動改程式、改任務狀態或代表授權執行。交辦時請明確指定待處理註解。
