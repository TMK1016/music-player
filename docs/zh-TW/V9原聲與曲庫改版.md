# V9 原聲、曲庫與中斷提示修復

版本：0.16.0／build23；日期：2026-10-29。

## 本輪範圍

已讀取工作區的 IMG_9858.png 與六張 Pasted image 202610291234xx.png，按標註修改，未將私人截圖／封面打包或提交 Git。

- 關閉 EQ：即時參數回到七段 0 dB、低音 0、音場關閉，顯示「原聲」；再開啟仍是原聲。取消手動調整儲存提示，但保留已儲存的模式與歌曲綁定，關閉期間歌曲綁定不會重新啟用EQ（包括重新啟動App）；重新開啟後切歌或明確選模式才按既有規則套用。
- 首頁位置：移除只接受清單／歌手標頭的過濾，記錄實際排名與歌曲錨點，避免 scrollPosition 持續回傳舊錨點；相同位置不重複發布。排行榜內容明確參與 scroll target layout。
- 中斷提示：移除 onInterruption 將訊息交給全域 alert 的行為；保留暫停、位置保存、待完成播放取消及系統媒體狀態。回到 App 可直接按播放；本輪不強行搶回通話或其他 App 的音訊，也不宣稱系統中斷被禁止。
- 清單：雙欄封面卡片，預覽前三個＋新增卡片，下拉展開全部；亦提供「顯示全部／收合」按鈕，無需依賴手勢。排行榜始終在整個清單區塊之後，沒有巢狀垂直捲動。
- 詳情頁：清單／歌手共用獨立曲目頁，封面、名稱、曲數、綠色播放全部及完整 lazy 曲目列表。播放全部沿既有播放模式與該佇列執行，不偷偷清除使用者循環／隨機選擇。
- 歌手：三欄圓形頭貼、長按編輯／排序、拖曳排序、右上排序及新增歌手。空歌手保留可編輯，不會虛構匯入歌曲。
- 正在播放：六項工具置中，右側箭頭不參與工具列置中計算，系統輸出選擇器維持掛載。
- 迷你播放器：播放／暫停改白色；裝飾封面背景不接收觸控，避免透明 GeometryReader／圖片超出區域影響手勢。
- 排行榜：封面、單行歌名與歌手，排名在左、純數字次數在右。

## 驗證與限制

模型測試已加入 EQ關閉／重新開啟／音場清除、排名與歌曲位置紀錄、系統中斷後不彈窗且能再次播放。既有匯入、去重、播放政策、千首索引與保存回歸一併執行。舊版 migration 測試改用 EQ 開啟的輸入來獨立檢查參數範圍，避免與此次「關閉即原聲」新需求矛盾。

原生無聲 QA 使用正式介面與 1230 首合成曲目；可確認網格與完整詳情列表，不把它當成手機音訊／觸控驗收。macOS 原生 scroll-to-bottom／scroll-to-top 動作可回到頂部；實際觸控向上滑及自訂封面需要 iPhone 回歸。一般操作雜音 MP-013／014 仍保留待聽測，不宣稱根治。

最終雙平台編譯、手機部署、Git遠端核對及新測試包狀態於本文件交付紀錄補充。TestFlight會員／上傳狀態不因本輪修錯而改為完成。
