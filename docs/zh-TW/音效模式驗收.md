# v0.4 驗收記錄

日期：2026-10-24。實作為 Swift／Apple 音訊，沒有改稱 Rust DSP。

- `python3 scripts/check_audio.py`：本機音檔交易式匯入、內容去重、損壞索引保護、播放／拖曳／自然結束／循環／中斷及設定還原；新增 13 預設、自訂新增／改名／覆蓋／刪除、20 組上限、空白／重名拒絕、歌曲綁定與恢復一般音效、v1 移轉／v2 還原、車輛持久化、各座位獨立距離、最遠距離延遲公式與不完整資料拒絕。
- 原生 GUI 驗證器使用 AVAudioEngine 離線渲染 PCM，不經喇叭輸出：1 kHz EQ +6.00 dB、旁通保留補償差 −6.00 dB；低架 +6 dB 時 32 Hz 實測 +5.91 dB，4 kHz 增益差小於 0.3 dB；演唱會殘響尾音 RMS 0.00079682，主旁通尾音 RMS 0。測試共用正式程式的 SoundEffectSettings。
- `generate_channel_checks.py` 生成原創左右／中央音像 WAV，檢查靜音側樣本全為零、峰值小於 820/32767、雙聲道 44.1 kHz、2 秒。
- Mac 原生預覽已操作：13 模式顯示，演唱會選取更新 EQ／空間與混合量；儲存「Fiesta 試聽」後自訂模式 1/20 並顯示其設定；車輛頁呈現 Fiesta、藍牙、前分音後同軸、6 位置、聲道試音、距離表與硬體限制。使用獨立 bundle ID 的預覽，沒有改寫正式 App 的音效偏好。

最終建置：macOS arm64 Debug 與 generic iOS Simulator arm64 Debug 均 `BUILD SUCCEEDED`。iOS 僅編譯，沒有宣稱模擬器／真機執行通過。流程驗證：25 節點、6 日誌版本、21 項改動，依賴無環、節點／檔案有效、HTML 與原生副本一致，JavaScript 語法通過。原生 bundle 版本 0.4.0，原創音檔與最終日誌逐一比對一致。

另已通過試音狀態測試：測試期間音效調整不污染測試音、完成不自動播歌、明確恢復時保留歌曲位置、重新選曲取消試音。沒有實車頻響／音量／藍牙車機測試，沒有逐路分音或真正多聲道測試；不得把數位 PCM 驗證當成車內聽感改善證據。此次亦不等於新版已安裝到手機；前次手機啟動仍待開發者憑證信任確認。

實作位置：`SoundProfiles.swift`、`PlayerModel.swift`、`AudioPlayback.swift`、`ProfileControls.swift`、`EqualizerView.swift`、`VehicleView.swift`、`VehicleCalibration.swift`。測試位置：`Tests/AudioChecks.swift`、`Tests/NativeEQChecks.swift`；測試產物在忽略版控的 `.build/checks/`。
