# v0.7 移除全部車輛設定

2026-10-26，使用者在實作期間明確取消此功能，優先於舊規格。

已移除：車輛設定頁、車名／連線／前後喇叭／超低音／座位模型、所有導航入口、聲道識別試音及其3份WAV的App打包。舊頁面原始碼與資源只保存在專案archive/retired-vehicle，供歷史日誌定位，不編譯、不隨新版App出貨。

啟動時以PreferencesCleanup清理UserDefaults現用orca.ui.settings.v1與before7band備份中的vehicle與seatDistances；SavedSettings不再解碼或編碼車輛模型。保留歌曲、收藏、EQ、低音、空間、自訂模式、綁定與新曲庫資料。舊偏好非JSON或已損毀時不盲目覆寫；模型不再使用其中的車輛資料。

原始歷史開發文件、Git歷史及過去ZIP保留當時範圍，不宣稱清除了所有舊備份；新版開發日誌仍可讀到歷史文字，但已移除功能不再有導航入口。此為對App功能／設定的清除，不會刪除使用者筆記或研究文件。

手機既有資料需安裝並啟動新版後才清理。本次若未完成手機安裝，不得宣稱已清除手機資料。模型測試覆蓋舊vehicle移除、EQ保留、再編碼不含車輛及舊日誌目的地無效。
