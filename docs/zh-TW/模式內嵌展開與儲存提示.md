# 模式內嵌展開與儲存提示 · v0.6.1

模式列橫向互動或點「全部」後，在原橫欄下方展開自適應模式格；點「收合」回到單列。選擇模式不會開啟新視窗，管理選單仍支援改名、覆蓋、刪除與還原內建模式。

手動調整任一 EQ 滑桿後，顯示「儲存新模式」按鈕；點擊才開啟命名表單。取消命名保留提示，滑桿回到調整前數值、選取模式、歸零或成功儲存／覆蓋後清除提示。重新命名既有模式不清除尚未儲存的調音。最多 20 組；達上限時可覆蓋或刪除原模式。

音訊濾波與餘裕策略不變。模型行為、macOS／iOS 編譯與流程日誌驗證結果由本次交付記錄補充；手機手勢及實車聽感需另行確認。
