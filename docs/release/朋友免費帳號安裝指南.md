# Music Player 原始碼測試包

此包供朋友在自己的 Mac 用 Xcode 編譯，安裝至自己的 iPhone／iPad；不是可直接點擊安裝的 IPA。需要 Xcode 支援的 macOS 與 iOS／iPadOS 17.0 以上裝置。使用較新版本 Xcode；若編譯器不支援專案 Swift 語法，更新 Xcode。

1. 解壓縮整個資料夾，不要只取出 xcodeproj。
2. 開啟 `Apple/OrcaPlayer.xcodeproj`。
3. Xcode → Settings → Accounts，登入自己的 Apple Account。不需提供帳號密碼給專案作者。
4. 左側選藍色專案圖示 → TARGETS → OrcaPlayer-iOS → Signing & Capabilities。勾選 Automatically manage signing，Team 選自己的 Personal Team。測試包已移除作者的 Development Team。
5. 將 Bundle Identifier 換成自己唯一的字串，例如 `com.yourname.musicplayer.test`，Debug／Release 皆使用相同值。第一次設定後記下此值，後續更新維持相同 Team 與 Bundle Identifier。
6. 用傳輸線連接已解鎖裝置，信任 Mac；依提示在「設定 → 隱私權與安全性 → 開發者模式」啟用並重新啟動。首次可能需等待 Xcode 準備裝置。
7. Xcode 頂端 Scheme 選 OrcaPlayer-iOS、執行裝置選自己的實體手機／平板；不要選 Any iOS Device。按 ▶︎ 或 ⌘R。
8. 如顯示不受信任的開發者，在裝置「設定 → 一般 → VPN與裝置管理」信任自己簽署的開發者。
9. App 啟動後可拔線使用。匯入自己有權使用的音訊；包內僅附專案原創的 Orca-Soundcheck.wav 示範音源，不含作者私人曲庫。

免費 Personal Team 的 provisioning profile 7 天到期，之後需接回 Mac 重新 Run。Apple 限制最多 3 台註冊裝置與每台 3 個免費開發 App。不要為更新先刪除 App，否則可能刪除 App 曲庫；維持相同 Team／Bundle Identifier 直接覆蓋更新。

目前版本：0.18.0／build25。功能為本機音樂播放、七段 EQ、低音、清單、評分及定時。藍牙操作雜音與 iPad 真機體驗仍待回報，不保證已消除所有問題。此包不含 TestFlight、付費會員資格或發佈簽章。內建反饋聯絡：admin@monstrai.com。

遇到簽章錯誤先確認 Team、唯一 Bundle Identifier、網路及裝置解鎖。遇到「build only device」請重新選實體裝置。請回報完整錯誤訊息、Xcode版本、裝置與系統版本，不傳送密碼、憑證或私人音樂。
